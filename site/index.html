How it works

01

Pair once

Each device makes its own key the first time it runs. Pair two devices by scanning a QR code or opening an invite link; both show the same safety code.

02

Send directly

Files go straight between the two devices when they can reach each other, and otherwise through a relay that only ever sees encrypted data.

03

Pause, resume, move on

Every chunk is checked. Pause from either side, resume later, or lose the connection: it picks up where it stopped.

Download

Android

Android 8 or newer. Open the APK on your phone and allow installing from that app when asked.

Windows

Windows 10/11, 64-bit. The installer isn't code-signed yet, so SmartScreen may ask: check the file first (below), then "More info" › "Run anyway".

Linux

AppImage for Ubuntu 22.04, Debian 12 or newer. chmod +x it, then run it (some systems need libfuse2).

Security and trust

End-to-end encrypted

Devices pin each other's keys: mutual TLS for files, sealed messages for pairing and offers. The mailbox and relay can't read or alter them.

No accounts

Keys are made and kept on your devices. The servers see which devices talk and when, never what they send. Details in the security model.

Built in the open

Apache-2.0 licensed. Every release file is built by GitHub from the tagged source, with checksums and a build attestation you can check.

To check a download came from this source and wasn't changed:

sha256sum -c SHA256SUMS.txt --ignore-missing
gh attestation verify <file> --repo Aditya-Karn234/PeerPayload

Early preview. It works, and it's tested on real devices, but it hasn't had an independent security audit. The free hosted servers sleep when idle, so the first pairing after a quiet spell can take up to a minute. Not yet: iOS and macOS apps.
